# Relevate Ruby SDK

Generated by Kaji for Ruby 3.1+. It only uses the Ruby standard library.

```sh
gem install relevate_sdk
```

```ruby
require "relevate_sdk"

client = RelevateSdk::Client.new(base_url: "https://api.example.com", api_key: ENV.fetch("API_KEY", nil))
client.contacts.get(contact_id: "contact_123")
```
