# Relevate Rust SDK

Generated by Kaji with the **resource-first** client surface.

```sh
cargo add relevate-sdk
```

Use it from an async context:

```rust
use relevate_sdk::*;

let client = Client::new("https://api.example.com");
let response = client.crm().list_crm_lists(ListCrmListsRequest::default()).await?;
println!("{response:?}");
```

See [STYLE_GUIDE.md](STYLE_GUIDE.md) for the public surface.
